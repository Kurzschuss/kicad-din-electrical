# kicad-din-electrical

KiCad library project for DIN/IEC electrical engineering components.

## Project goal

This project aims to provide reusable KiCad symbols, footprints and supporting resources for DIN rail electrical engineering documentation.

## Planned structure

- `symbols/` - KiCad schematic symbols
- `footprints/` - KiCad footprints where applicable
- `3dmodels/` - optional 3D models
- `examples/` - example schematics
- `docs/` - project documentation
