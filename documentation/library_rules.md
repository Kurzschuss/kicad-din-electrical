# KiCad DIN Electrical Library Rules

## Symbol classes

- DIN_Power: protection devices and power switching
- DIN_Control: 24V control components
- DIN_Safety: safety relays and emergency stop circuits
- DIN_Terminals: DIN rail terminals
- DIN_Indicators: status indicators

## Standard fields

- Reference
- Value
- Function
- Manufacturer
- Product_Family
- Part_Number
- Voltage
- Current_Rating
- Mounting
- DIN_Width
- Footprint
- 3D_Model
- Datasheet
- Alternative
