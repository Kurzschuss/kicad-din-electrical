# Terminal Block System Example

## Purpose

Defines a DIN rail terminal numbering concept for control cabinets.

## Terminal groups

### X1 - Power supply

- X1.1 - L1
- X1.2 - L2
- X1.3 - L3
- X1.4 - PE

### X2 - Control voltage

- X2.1 - +24V
- X2.2 - 0V

### X3 - Field devices

- X3.1 - Start signal
- X3.2 - Stop signal
- X3.3 - Motor enable

## Rules

- Terminal references are unique within the cabinet.
- Power and control terminals use separate groups.
- PE terminals are clearly identified.
- Cross references are maintained in schematics.
