# Control Cabinet Basic - Terminal Plan

## X1 Incoming Power

| Terminal | Signal |
|---|---|
| X1.1 | L1 |
| X1.2 | L2 |
| X1.3 | L3 |
| X1.4 | PE |

## X2 Control Supply

| Terminal | Signal |
|---|---|
| X2.1 | +24V DC |
| X2.2 | 0V |

## X3 Field Connections

| Terminal | Signal |
|---|---|
| X3.1 | Start button |
| X3.2 | Stop button |
| X3.3 | Motor enable |

## Rules

- Power terminals are separated from control terminals.
- Terminal references are unique.
- Field wiring is connected through terminal blocks.
