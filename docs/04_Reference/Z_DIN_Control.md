# Z_DIN_Control

## Zweck

`Z_DIN_Control` ist eine Symbol- und Footprintbibliothek für Steuer- und Bedienelemente im Bereich der Elektroplanung.

## Dateien

```text
symbols/DIN_Electrical_Symbols/Z_DIN_Control.kicad_sym
footprints/Z_DIN_Control.pretty/
```

## Verwendung in KiCad

Symbolbibliotheksname:

```text
Z_DIN_Control
```

Footprintbibliotheksname:

```text
Z_DIN_Control
```

Eine Symbol-ID aus dieser Bibliothek verwendet das Format:

```text
Z_DIN_Control:<Symbolname>
```

Eine Footprint-ID verwendet das Format:

```text
Z_DIN_Control:<Footprintname>
```
