# Z_DIN_Module_18mm

## Zweck

`Z_DIN_Module_18mm` beschreibt einen vorhandenen Footprint für ein DIN-Reiheneinbaugerät mit einer Modulbreite von 18 mm.

## Footprintdatei

```text
Z_DIN_Module_18mm.kicad_mod
```

## Qualifizierte Footprint-ID

```text
Z_DIN_Module_18mm:Z_DIN_Module_18mm
```

Dabei ist:

- links vom Doppelpunkt der Name des `.pretty`-Ordners ohne Endung,
- rechts vom Doppelpunkt der interne Footprintname.

## Verwendung

Die zugehörige `.pretty`-Bibliothek muss in KiCad unter dem Namen `Z_DIN_Module_18mm` registriert sein.
