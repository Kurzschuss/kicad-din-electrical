## Namensregel

Der Bibliotheksname in KiCad entspricht dem Dateinamen ohne `.kicad_sym`.

Beispiel:

```text
Datei: Z_DIN_Control.kicad_sym
Bibliotheksname: Z_DIN_Control
```

Eine qualifizierte Symbol-ID hat dieses Format:

```text
<Bibliothek>:<Symbol>
```
