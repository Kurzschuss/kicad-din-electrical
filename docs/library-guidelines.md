# KiCad Library Design Guidelines

## Symbol fields

Every symbol should use these fields where applicable:

- Reference
- Value
- Manufacturer
- Part Number
- Description
- Datasheet
- DIN/IEC Reference

## Naming scheme

Prefixes:

- X_ : terminals and connectors
- F_ : protection devices
- K_ : contactors and relays
- S_ : switches and controls
- Q_ : switching devices
- M_ : motors

## Graphic rules

- Use IEC-oriented representations
- Keep symbols manufacturer independent
- Use consistent pin naming
- Prefer functional descriptions over product names

## Documentation

DIN and IEC references should be documented in symbol properties, not hard-coded into the symbol name.
