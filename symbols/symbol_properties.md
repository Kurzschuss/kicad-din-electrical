# IEC 60617 Symbol Properties

## Standard Fields

- Reference
- Value
- Manufacturer
- Part Number
- Footprint
- Datasheet
- Description

## Reference Prefixes

- Q: Circuit breakers, protection devices
- F: Fuses
- K: Contactors and relays
- S: Switches
- X: Terminals

## Electrical Data

- Rated voltage
- Rated current
- Number of poles
- Connection type

## Documentation

Symbols are prepared for DIN/IEC based electrical documentation in KiCad.
