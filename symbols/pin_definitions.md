# IEC 60617 Pin Definitions

## RCD / FI

- Input: L1 L2 L3 N
- Output: T1 T2 T3 N
- PE: Protective Earth where applicable

## MCB

- Pole 1: 1-2
- Pole 2: 3-4
- Pole 3: 5-6
- Neutral: N-N

## Contactor

- Coil: A1 / A2
- Main contacts: 1-2, 3-4, 5-6
- Auxiliary contacts: 13-14, 21-22

## Motor Protection

- Power input: 1L1 3L2 5L3
- Power output: 2T1 4T2 6T3
- Auxiliary contacts: 95-96 / 97-98

## Main Switch

- Incoming: 1-3-5
- Outgoing: 2-4-6
