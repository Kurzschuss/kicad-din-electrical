# Control Cabinet Basic V1.0

## DIN Rail Layout

### Rail 1 - Power

| Position | Device | Function |
|---|---|---|
| 1 | X1 | Power input terminals |
| 2 | Q1 | ABB motor protection |
| 3 | K1 | ABB contactor |
| 4 | Reserve | Spare space |

### Rail 2 - Control

| Position | Device | Function |
|---|---|---|
| 1 | K2 | ABB safety relay |
| 2 | Q2 | Hager control protection |
| 3 | X2 | Control terminals |
| 4 | X3 | Field terminals |

## Mechanical Rules

- DIN rail TS35
- Keep power and control separated
- Minimum 20% reserve space
- PE routing directly to PE rail
