# Z_I_ElectricalComponents footprint library

Diese gleichnamige `.pretty`-Bibliothek ist absichtlich ohne konkrete Footprints angelegt.

Die importierten Z_I-Symbole stammen aus herstellerneutralen JS/SVG-Quellen.
Es werden keine nicht belegten Gehäuse- oder Footprintzuordnungen erfunden.

Konkrete Footprints werden später nur auf Basis belastbarer Geräte- oder
Herstellerdaten ergänzt.
